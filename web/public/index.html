Wepic Live — 실시간 사진 액자

구글 포토의 사진·동영상을 골라 감성 슬라이드쇼로 보여주고, 링크 하나로 가족과 함께 감상하는 웹 액자입니다.

  • 구글 포토에서 사진 선택 → 자동 슬라이드쇼
  • 배경음악 · 전환효과(페이드/슬라이드/켄번즈) · 시계·날씨 · 제목 오버레이
  • 실시간 공유 링크 — 로그인 없이 열람
  • 동영상 재생 · 폰에서 "공유"로 바로 보내기(PWA 설치)

왼쪽 메뉴에서 Google 로그인 또는 데모로 보기로 시작하세요.

구글 계정 연동

Google 계정으로 로그인하면 구글 포토에서 사진을 선택해 액자로 볼 수 있습니다.

표시할 사진 선택

먼저 왼쪽 Google 로그인이 필요합니다.

  1. “사진 선택 시작” 클릭 또는 QR 스캔
  2. 로그인된 계정으로 선택하세요 (폰에 여러 계정이 있으면 다른 계정을 고르면 선택이 완료되지 않습니다)
  3. 검색창에 인물 이름(예: 아버지) 또는 장소명 입력
  4. 원하는 사진들을 선택 후 완료
