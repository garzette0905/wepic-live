Wepic Live — 실시간 사진 액자

구글 포토의 사진·동영상을 골라 감성 슬라이드쇼로 보여주고, 링크 하나로 가족과 함께 감상하는 웹 액자입니다.

  • 구글 포토에서 사진 선택 → 자동 슬라이드쇼
  • 배경음악 · 전환효과(페이드/슬라이드/켄번즈) · 시계·날씨 · 제목 오버레이
  • 실시간 공유 링크 — 로그인 없이 열람
  • 동영상 재생 · 폰에서 "공유"로 바로 보내기(PWA 설치)

위쪽 메뉴에서 로그인 또는 데모로 보기로 시작하세요.

로그인

가입할 때 쓰신 계정으로 로그인하세요. 처음이시면 회원가입을 눌러주세요.

Google로 로그인하면 구글 포토에서 사진을 골라올 수 있습니다.
카카오·네이버는 기기(갤러리)에 있는 사진을 직접 올리는 방식으로 이용합니다.

로그아웃

회원가입

별도의 아이디·비밀번호를 만들지 않습니다. 가지고 계신 Google 또는 카카오 계정으로 바로 시작하며, 아래 버튼을 누르면 그 즉시 가입이 완료됩니다(승인 대기 없음).

이용안내

  • Wepic Live는 고른 사진을 슬라이드쇼로 보여주고, 링크 하나로 가족과 공유하는 서비스입니다.
  • 공유 링크는 로그인 없이 열람할 수 있으므로, 링크를 받은 사람은 누구나 볼 수 있습니다. 원치 않으시면 PIN(4자리)을 걸어두세요(기본으로 자동 발급됩니다).
  • 사진 업로드·공유 링크 만들기는 로그인한 회원만 할 수 있습니다.
  • 공유한 사진은 따로 지우실 때까지 보관됩니다(자동 삭제 없음). 직접 지우려면 My사진관리에서 삭제하시면 즉시 링크가 닫힙니다.
  • 개인이 만든 서비스로 무료 제공되며, 장애·중단에 대한 보상은 어렵습니다.

개인정보 수집·이용 안내

  • 수집 항목: 로그인 제공자가 알려주는 계정 고유번호, 이름(닉네임), 이메일(제공자가 주는 경우에만 — 카카오는 주지 않을 수 있습니다).
  • 비밀번호는 받지도, 저장하지도 않습니다. 로그인은 Google·카카오가 처리합니다.
  • 이용 목적: 회원 식별(내가 만든 액자를 나에게만 보여주기), 서비스 운영·문의 대응.
  • 사진·동영상: 공유 링크를 만들 때 서버(Cloudflare R2)에 저장되며, 링크를 아는 사람(또는 PIN을 아는 사람)이 볼 수 있습니다.
  • 보관 기간: 회원 정보는 탈퇴 요청 시까지, 사진은 직접 삭제할 때까지.
  • 제3자 제공 없음. 광고·마케팅에 쓰지 않습니다.
  • 문의·삭제 요청: garzette@paran.com

두 항목에 모두 동의하시면 아래 가입 버튼이 활성화됩니다.

이미 가입하셨다면 로그인으로 가세요.

표시할 사진 선택

먼저 위쪽 메뉴에서 로그인이 필요합니다.

  1. “사진 선택 시작” 클릭 또는 QR 스캔
  2. 로그인된 계정으로 선택하세요 (폰에 여러 계정이 있으면 다른 계정을 고르면 선택이 완료되지 않습니다)
  3. 검색창에 인물 이름(예: 아버지) 또는 장소명 입력
  4. 원하는 사진들을 선택 후 완료

기기(갤러리)에 있는 사진을 직접 골라 올립니다.

  1. “갤러리에서 사진 선택” 클릭
  2. 원하는 사진들을 선택 (여러 장 가능)
  3. 선택하면 바로 슬라이드쇼가 시작됩니다

동영상은 공유 링크에 담기지 않아 사진만 선택됩니다.
